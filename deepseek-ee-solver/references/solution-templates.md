# 解题模板 / Solution Templates

## 0. 计算题五步规范（职高教材要求 / required format）

1. **解：** 开头必须写「解：」
2. **定参考方向**：声明 i₁、i₂ 等电流的参考方向（决定 KCL 符号）；图上或文字标注。
3. **写已知相量**：瞬时值 → 有效值相量（İ = I∠ψ，I 为有效值）；列已知量（带单位）。
4. **列式 → 代数 → 结果**：先写公式名（分流/分压/欧姆定律…），再代入数据，最后结果带单位（A、V、Ω、W、var、V·A）。相量结果写极坐标：8∠−120° A。
5. **校验**：KCL/KVL、量纲、逐点抽查（用 `tools/ee.py`）。
6. **反变换 + 答：** 相量 → 瞬时值（i = I√2 sin(ωt + ψ) A），结尾写「答：…」。

## 1. 直流电路 / DC circuits

```
解：设 i₁ 自左向右流过 R₁……
R总 = R₁ + R₂ = 100 + 200 = 300 Ω          （串联）
U₁ = U·R₁/(R₁+R₂) = …                      （分压）
İ₁ = İ·R₂/(R₁+R₂) = …                      （分流，注意分母为两支路之和）
P = UI = I²R = U²/R
校验：ΣI = 0（KCL），ΣU = 0（KVL）
```

## 2. 单相正弦交流 / Single-phase AC（相量法三步）

```
① 瞬时值 → 相量：i = 12√2 sin(314t − 120°) A ⟹ İ = 12∠−120° A
② 复运算：
   Z = R + j(XL − XC)；XL = ωL；XC = 1/(ωC)
   Ů = Z·İ；分流/分压与直流同形
③ 相量 → 瞬时值：i = I√2 sin(314t + ψ) A
```

纯电阻并联：各电流与总电流**同相**，直接按电阻反比分流。

## 3. RLC 串/并联 / RLC series-parallel

- 串联：Z = R + j(XL − XC)，|Z| = √(R² + (XL−XC)²)，φ = arctan((XL−XC)/R)
- 阻抗三角形 / 电压三角形 / 功率三角形三者相似
- P = UIcosφ（W）、Q = UIsinφ（var）、S = UI（V·A）、cosφ = P/S
- 谐振（串联）：XL = XC，f₀ = 1/(2π√LC)，Z 最小，电流最大，UL = UC = Q·U
- 并联支路：导纳相加，分流公式 Z 对换位置

## 4. 三相电路 / Three-phase

```
Y 接：U线 = √3·U相，I线 = I相；Δ 接：U线 = U相，I线 = √3·I相
对称负载有功：P = √3·UL·IL·cosφ（UL、IL 均为线值）
校验：İA + İB + İC = 0（对称时）
```

## 5. 变压器 / Transformer

```
k = U₁/U₂ = N₁/N₂ = I₂/I₁
S = U₁I₁ = U₂I₂（理想）
校验：输入/输出功率平衡
```

## 6. 电动机 / Motor

```
三相异步：P入 = √3·UL·IL·cosφ；P出 = P入·η
额定电流估算（380 V 鼠笼）：IN ≈ 2P(kW)
Y-Δ 启动：启动电流/转矩为直接启动的 1/3
```

## 7. 理论题（选择/判断）/ Theory questions

1. 抓关键词（“有效值”“超前/滞后”“谐振”“安全电压”）。
2. 定位概念 → 查 `formulas.md` 或 `safety-regs.md` 对应条目。
3. 排除法：先删明显违背量纲/单位的选项。
4. 判断题警惕绝对化措辞（“一定”“任何”“只要”），安全规程类按条文原文判断，不自行推理。
5. 单位陷阱：把选项统一成相同单位再比较。

## 8. 书写红线 / Format red lines（老师扣分点）

| ❌ | ✔ |
|---|---|
| 相量小写 i = 8∠−120° | İ = 8∠−120° A |
| 相量含 sin | 相量只写 İ = I∠ψ；sin 只在瞬时式 |
| 相量模用幅值 8√2 | 相量模用有效值 8 |
| 瞬时式漏 √2 | i₁ = 8√2 sin(314t − 120°) A |
| 无单位/无 ° | 8∠−120° A |
| 缺「解：/答：」或缺参考方向 | 按五步规范写全 |
