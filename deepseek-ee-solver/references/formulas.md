# 公式速查 / Formula Reference

按职高《电工基础》+ 低压电工证范围。所有相量公式用**有效值**。
Vocational《电工基础》+ low-voltage certificate scope. Phasor formulas use RMS values.

## 1. 直流电路 / DC

| 名称 | 公式 |
|---|---|
| 欧姆定律 | U = IR |
| 功率 | P = UI = I²R = U²/R |
| 串联 | R = R₁ + R₂ + …；分压 U₁ = U·R₁/(R₁+R₂) |
| 并联 | 1/R = 1/R₁ + 1/R₂；分流 I₁ = I·R₂/(R₁+R₂) |
| 两电阻并联 | R = R₁R₂/(R₁+R₂) |
| KCL / KVL | ΣI = 0；ΣU = 0 |
| 最大功率传输 | RL = R内 时输出最大 |

## 2. 正弦交流三要素 / Sine-wave basics

| 名称 | 公式 |
|---|---|
| 三要素 | 幅值 Iₘ、角频率 ω、初相 ψ |
| 有效值 | I = Iₘ/√2 ≈ 0.707Iₘ |
| 角频率 | ω = 2πf = 314 rad/s（f = 50 Hz） |
| 周期 | T = 1/f = 20 ms |
| 相位差 | φ = ψ₁ − ψ₂（正=超前，负=滞后） |

## 3. R / L / C 元件特性 / Element behavior

| 元件 | 阻抗 | u-i 相位关系 |
|---|---|---|
| R | Z = R | 同相 φ = 0 |
| L | XL = ωL = 2πfL | 电压超前电流 90°（电流滞后） |
| C | XC = 1/(ωC) = 1/(2πfC) | 电流超前电压 90°（电压滞后） |

## 4. RLC 电路 / RLC circuits

| 名称 | 公式 |
|---|---|
| 串联阻抗 | Z = R + j(XL − XC)；\|Z\| = √(R² + (XL−XC)²) |
| 阻抗角 | φ = arctan((XL − XC)/R) |
| 有功功率 | P = UIcosφ = I²R（W） |
| 无功功率 | Q = UIsinφ = I²X（var） |
| 视在功率 | S = UI（V·A）；S² = P² + Q² |
| 功率因数 | cosφ = P/S = R/Z |
| 串联谐振 | XL = XC；f₀ = 1/(2π√LC)；Z = R 最小、I 最大 |
| 品质因数 | Q = UL/U = XL/R |

## 5. 三相 / Three-phase

| 名称 | 公式 |
|---|---|
| Y 接 | U线 = √3·U相；I线 = I相 |
| Δ 接 | U线 = U相；I线 = √3·I相 |
| 对称负载功率 | P = √3·UL·IL·cosφ |
| 相序 | A→B→C，正相序 |

## 6. 变压器与电动机 / Transformer & motor

| 名称 | 公式 |
|---|---|
| 变比 | k = U₁/U₂ = N₁/N₂ = I₂/I₁ |
| 容量 | S = U₁I₁ = U₂I₂ |
| 电机输入功率 | P入 = √3·UL·IL·cosφ |
| 电机输出功率 | P出 = P入·η |
| 380 V 电机估算 | IN ≈ 2·P(kW) |
| Y-Δ 启动 | 启动电流/转矩 = 直接启动的 1/3 |

## 7. 常用换算 / Conversions

| 换算 | 值 |
|---|---|
| 1 kW = | 1000 W |
| 1 MΩ = | 10⁶ Ω |
| 1 mH / 1 μF | 10⁻³ H / 10⁻⁶ F |
| √2 / √3 | 1.414 / 1.732 |
| 1/√2 / 1/√3 | 0.707 / 0.577 |
